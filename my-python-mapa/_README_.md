## 🚀 С чего начать


### Step 1: Установка Python
1. Скачайте и установите актуальную версию **Python** с официального сайта: [python.org](https://www.python.org/downloads/).
2. Прочитать инструкцию по установке.
3. При установке *(для Windows)* обязательно отметьте галочку **"Add Python to PATH"**.

---

### Step 2: Выбор среды разработки (IDE / Редактора)
Для комфортной работы и написания кода выберите один из популярных инструментов. Не существует одного «самого лучшего» инструмента — выбор зависит от ваших личных предпочтений и задач. Почитайте об особенностях популярных платформ и выберите ту, которая покажется вам наиболее удобной для старта

💡 **Совет:** На этапе обучения попробуйте пару разных вариантов, чтобы понять, в каком интерфейсе вам комфортнее работать.
